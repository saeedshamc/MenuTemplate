# منوی دیجیتال کلویی 🍗 — نسخه React (آماده Vercel)

منوی رستورانی برای فروشگاه‌های زنجیره‌ای سوخاری **کلویی**، این بار به‌صورت یک پروژه‌ی استاندارد **React + Vite** که مستقیم روی Vercel قابل دیپلوی است.

## اجرا روی سیستم خودتان

```bash
npm install
npm run dev
```

سپس آدرسی که در ترمینال نمایش داده می‌شود (معمولاً `http://localhost:5173`) را باز کنید.

برای گرفتن نسخه‌ی build نهایی:

```bash
npm run build
npm run preview
```

## دیپلوی روی Vercel

### روش ۱ — از طریق گیت‌هاب (پیشنهادی)
1. یک ریپازیتوری جدید در گیت‌هاب بسازید و این پوشه را در آن Push کنید:
   ```bash
   git init
   git add .
   git commit -m "منوی کلویی"
   git branch -M main
   git remote add origin <آدرس-ریپازیتوری-شما>
   git push -u origin main
   ```
2. وارد [vercel.com](https://vercel.com) شوید → **Add New Project** → ریپازیتوری را انتخاب کنید.
3. Vercel به‌صورت خودکار تشخیص می‌دهد که پروژه از نوع **Vite** است:
   - Build Command: `npm run build`
   - Output Directory: `dist`
4. روی **Deploy** بزنید. چند ثانیه بعد لینک زنده سایت آماده است.

### روش ۲ — مستقیم از طریق Vercel CLI
```bash
npm install -g vercel
vercel login
vercel        # برای دیپلوی پیش‌نمایش
vercel --prod # برای دیپلوی نهایی روی دامنه اصلی
```
در طول اجرای `vercel`، فقط سؤالات پیش‌فرض را با Enter رد کنید؛ تنظیمات (Vite / dist) به‌صورت خودکار شناسایی می‌شوند.

## ساختار پروژه

```
sokhari/
├── index.html          ← نقطه ورود Vite و بارگذاری فونت‌ها
├── package.json
├── vite.config.js
└── src/
    ├── main.jsx         ← رندر React روی صفحه
    ├── App.jsx          ← کامپوننت اصلی (جستجو، فیلتر، سبد خرید)
    ├── data.js          ← دسته‌بندی‌ها و ۲۰ محصول (اسم، قیمت، زمان آماده‌سازی، مواد اولیه)
    ├── icons.jsx        ← تصویرسازی‌های SVG اختصاصی هر غذا و لوگو
    └── styles.css       ← تمام استایل‌ها و رنگ‌بندی برند
```

## امکانات

- 🔎 جستجوی زنده روی نام غذا، مواد تشکیل‌دهنده و نام دسته‌بندی
- 🏷️ فیلتر بر اساس دسته‌بندی (سوخاری کلاسیک، ساندویچ، استریپس، بال و کتف، پیش‌غذا، نوشیدنی، سس)
- 💰 قیمت هر محصول به تومان و ⏱️ زمان آماده‌سازی
- 🧾 لیست مواد تشکیل‌دهنده روی هر کارت
- 🛒 سبد خرید (افزودن/کم‌کردن) با جمع کل زنده
- 🏆 نشان‌های «پرفروش»، «تند» و «جدید»
- 📱 طراحی کاملاً واکنش‌گرا

## نکته درباره تصاویر

به‌جای عکس‌های استوک اینترنتی (که کپی‌رایت دارند)، برای هر محصول یک تصویرسازی SVG اختصاصی و هماهنگ با برند طراحی شده — کاملاً قابل استفاده تجاری و قابل ویرایش در `src/icons.jsx`.

### جایگزینی با عکس واقعی محصولات
1. عکس‌ها را در `public/images/` قرار دهید (مثلاً `public/images/1.jpg`).
2. در `src/App.jsx`، داخل `card-media`، به‌جای `<FoodArt />` بنویسید:
   ```jsx
   <img src={`/images/${product.id}.jpg`} alt={product.name} style={{ width: '100%', height: '100%', objectFit: 'cover' }} />
   ```

## شخصی‌سازی سریع

- **قیمت‌ها و محصولات:** `src/data.js`
- **رنگ برند:** متغیرهای بالای `src/styles.css` (بخش `:root`): `--crust`, `--gold`, `--char`
- **نام و لوگو:** `src/App.jsx` (`<h1>کلویی</h1>`) و `Icons.Logo` در `src/icons.jsx`
