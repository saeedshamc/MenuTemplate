# منوی دیجیتال کلویی 🍗

منوی رستورانی برای فروشگاه‌های زنجیره‌ای سوخاری **کلویی**، ساخته‌شده با React (بدون نیاز به نصب یا Build).

## اجرا

فقط فایل `index.html` را با یک مرورگر (Chrome, Edge, Firefox) باز کنید. برای بهترین نتیجه یک سرور محلی ساده اجرا کنید (اختیاری):

```bash
npx serve .
# یا
python3 -m http.server 8000
```

سپس آدرس نمایش‌داده‌شده را در مرورگر باز کنید. اتصال اینترنت لازم است چون React، فونت‌ها و Babel از CDN بارگذاری می‌شوند.

## ساختار فایل‌ها

```
sokhari/
├── index.html   ← صفحه اصلی و بارگذاری فونت‌ها/کتابخانه‌ها
├── style.css    ← تمام استایل‌ها، رنگ‌بندی برند و افکت‌ها
├── data.js      ← لیست دسته‌بندی‌ها و ۲۰ محصول (اسم، قیمت، زمان آماده‌سازی، مواد اولیه)
├── icons.js     ← تصویرسازی‌های برداری (SVG) اختصاصی هر غذا و لوگو
└── app.js       ← کامپوننت اصلی React (جستجو، فیلتر دسته‌بندی، سبد خرید)
```

## امکانات

- 🔎 جستجوی زنده روی نام غذا، مواد تشکیل‌دهنده و نام دسته‌بندی
- 🏷️ فیلتر بر اساس دسته‌بندی (سوخاری کلاسیک، ساندویچ، استریپس، بال و کتف، پیش‌غذا، نوشیدنی، سس)
- 💰 قیمت هر محصول به تومان
- ⏱️ زمان آماده‌سازی هر آیتم
- 🧾 لیست مواد تشکیل‌دهنده روی هر کارت
- 🛒 افزودن/کم‌کردن به سبد خرید با نمایش جمع کل به‌صورت زنده
- 🏆 نشان‌های «پرفروش»، «تند» و «جدید»
- 📱 طراحی کاملاً واکنش‌گرا (موبایل، تبلت، دسکتاپ)

## نکته درباره تصاویر

به‌دلیل محدودیت‌های کپی‌رایت روی عکس‌های استوک/اینترنتی، برای هر محصول یک **تصویرسازی برداری (SVG) اختصاصی و هماهنگ با هویت برند** طراحی شده (به‌جای استفاده از عکس‌های واقعی دیگران). این تصاویر:
- کاملاً قابل استفاده تجاری هستند (بدون نگرانی کپی‌رایت)
- سبک یکدست و تمیزی به کل منو می‌دهند
- به‌راحتی در فایل `icons.js` قابل ویرایش رنگ/فرم هستند

### جایگزینی با عکس واقعی محصولات
اگر می‌خواهید عکس واقعی غذاهای خودتان را جایگزین کنید:
1. عکس هر محصول را در پوشه‌ای مثل `images/` قرار دهید (مثلاً `images/sandwich-1.jpg`)
2. در `app.js`، داخل `card-media`، به‌جای `<FoodArt />` بنویسید:
   ```jsx
   <img src={`images/${product.id}.jpg`} alt={product.name} style={{width:'100%',height:'100%',objectFit:'cover'}} />
   ```
3. در `data.js` می‌توانید فیلد `image: 'images/1.jpg'` به هر محصول اضافه کنید.

## شخصی‌سازی سریع

- **قیمت‌ها و محصولات:** فایل `data.js` را ویرایش کنید.
- **رنگ برند:** متغیرهای بالای `style.css` (بخش `:root`) را تغییر دهید:
  - `--crust`: قرمز-قهوه‌ای اصلی برند
  - `--gold`: طلایی سرخ‌کردنی
  - `--char`: پس‌زمینه تیره
- **نام و لوگو:** در `app.js` داخل `<h1>کلویی</h1>` و تصویرسازی `Icons.Logo` در `icons.js`.
