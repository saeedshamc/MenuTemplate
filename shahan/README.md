# شاهان — چلوکبابی سنتی

منوی دیجیتال چلوکبابی با حال‌وهوای لوکس ایرانی؛ بورگاندی عمیق، مس و طلا، جستجو، فیلتر دسته، تم روشن/تاریک و آمادهٔ دیپلوی.

## اجرا

```bash
npm install
npm run dev
```

## ساخت نسخه نهایی

```bash
npm run build
npm run preview
```

## شخصی‌سازی

- محصولات و قیمت‌ها: `src/data/menuData.js`
- رنگ و حال‌وهوا: متغیرهای CSS در `src/index.css`
- لوگو و هیرو: `public/logo.png` و `public/hero.png`
