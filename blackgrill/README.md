# بلک‌گریل — برگر جوینت

منوی دیجیتال برگر با حال‌وهوای شهری شب؛ زغال سیاه، اکسنت لایم الکتریک، جستجو، فیلتر دسته، تم روشن/تاریک و آمادهٔ دیپلوی.

## اجرا

```bash
npm install
npm run dev
```

## ساخت نسخه نهایی

```bash
npm run build
npm run preview
```

## شخصی‌سازی

- محصولات و قیمت‌ها: `src/data/menuData.js`
- رنگ و حال‌وهوا: متغیرهای CSS در `src/index.css`
- لوگو و هیرو: `public/logo.png` و `public/hero.png`


## مدیریت محصولات

در سایت روی **مدیریت** بزنید یا به `#admin` بروید.
رمز پیش‌فرض: `admin123`

از پنل می‌توانید محصول اضافه/ویرایش/حذف کنید، عکس آپلود کنید، دسته‌ها و تنظیمات سایت را عوض کنید و پشتیبان JSON بگیرید.
