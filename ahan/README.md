# آهن‌وآتش — استیک‌هاوس

منوی دیجیتال فاین‌داینینگ با برندینگ تیره و طلایی، لوگو و هیرو اختصاصی، جستجو، فیلتر دسته، تم روشن/تاریک.

## اجرا

```bash
npm install
npm run dev
```

## شخصی‌سازی

- محصولات: `src/data/menuData.js`
- رنگ‌ها: `src/index.css`
- لوگو و هیرو: `public/logo.png` و `public/hero.png`
