# داگ‌استریت — هات‌داگ و اسنک بار

منوی دیجیتال خیابانی با هویت خردل و کetchup، لوگو و هیرو اختصاصی.

```bash
npm install
npm run dev
```


## مدیریت محصولات

در سایت روی **مدیریت** بزنید یا به `#admin` بروید.
رمز پیش‌فرض: `admin123`

از پنل می‌توانید محصول اضافه/ویرایش/حذف کنید، عکس آپلود کنید، دسته‌ها و تنظیمات سایت را عوض کنید و پشتیبان JSON بگیرید.
