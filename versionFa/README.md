# ذائقه — نمونه‌کار منوی رستوران، کافه و بستنی‌فروشی

یک پروژه‌ی نمونه (Portfolio) با React + Vite برای نمایش منوی رستوران، کافه و بستنی‌فروشی در یک صفحه.

## امکانات
- بیش از ۷۰ محصول متنوع در سه بخش: رستوران، کافه، بستنی‌فروشی
- عکس اختصاصی برای هر محصول (به‌صورت خودکار از سرویس تصویر آنلاین بارگذاری می‌شود؛ در صورت قطع اینترنت یا خطای بارگذاری، به‌طور خودکار ایموجی جایگزین نمایش داده می‌شود)
- جست‌وجوی زنده بین نام، توضیحات و دسته‌بندی آیتم‌ها
- فیلتر بر اساس بخش (رستوران/کافه/بستنی‌فروشی) و دسته‌بندی داخلی هرکدام (مثل پیش‌غذا، غذای اصلی، قهوه، بستنی فانتزی و...)
- شمارنده‌ی تعداد نتایج فیلتر/جست‌وجو
- حالت تاریک (Dark) و روشن (Light) با ذخیره‌سازی انتخاب کاربر
- طراحی راست‌به‌چپ (RTL) و ریسپانسیو برای موبایل

> نکته: تصاویر محصولات از یک سرویس تصویر رایگان و آنلاین بر اساس کلیدواژه‌ی هر محصول گرفته می‌شوند (نیاز به اتصال اینترنت هنگام اجرا دارد). برای استفاده‌ی واقعی و حرفه‌ای، توصیه می‌شود عکس‌های واقعی منوی خودتان را در پوشه‌ای مثل `src/assets` قرار داده و مقدار `img` هر آیتم در `menuData.js` را به مسیر عکس محلی تغییر دهید.

## اجرا
```bash
npm install
npm run dev
```

سپس آدرس نمایش داده‌شده در ترمینال (معمولاً http://localhost:5173) را در مرورگر باز کنید.

## ساخت نسخه‌ی نهایی (Build)
```bash
npm run build
npm run preview
```

## ساختار پروژه
```
src/
  data/menuData.js      داده‌های نمونه‌ی منو
  components/
    ThemeToggle.jsx      دکمه‌ی تغییر تم
    SearchBar.jsx        نوار جست‌وجو
    MenuCard.jsx         کارت نمایش هر آیتم منو
  App.jsx                منطق اصلی صفحه
  index.css              استایل‌ها و متغیرهای تم
```

## شخصی‌سازی
- برای تغییر یا افزودن آیتم‌های منو، فایل `src/data/menuData.js` را ویرایش کنید.
- رنگ‌ها و ظاهر کلی از طریق متغیرهای CSS در ابتدای فایل `src/index.css` قابل تغییرند.
