# دلچین — نمونه‌کار منوی رستوران، کافه و بستنی‌فروشی

یک پروژه‌ی نمونه (Portfolio) با React + Vite برای نمایش منوی رستوران، کافه و بستنی‌فروشی در یک صفحه، با برندینگ اختصاصی «دلچین».

## امکانات
- برند و لوگوی اختصاصی «دلچین» (لوگو به‌صورت SVG و بدون وابستگی به فایل خارجی)
- بک‌گراند هیرو (Hero) با تصویر غذای اشتها‌آور و گرادیان تیره‌ی هماهنگ با هر دو تم روشن/تاریک
- بیش از ۷۰ محصول متنوع در سه بخش: رستوران، کافه، بستنی‌فروشی
- عکس اختصاصی برای هر محصول (به‌صورت خودکار از سرویس تصویر آنلاین بارگذاری می‌شود؛ در صورت قطع اینترنت یا خطای بارگذاری، به‌طور خودکار ایموجی جایگزین نمایش داده می‌شود)
- جست‌وجوی زنده بین نام، توضیحات و دسته‌بندی آیتم‌ها
- فیلتر بر اساس بخش (رستوران/کافه/بستنی‌فروشی) و دسته‌بندی داخلی هرکدام (مثل پیش‌غذا، غذای اصلی، قهوه، بستنی فانتزی و...)
- شمارنده‌ی تعداد نتایج فیلتر/جست‌وجو
- حالت تاریک (Dark) و روشن (Light) با ذخیره‌سازی انتخاب کاربر
- طراحی راست‌به‌چپ (RTL) و ریسپانسیو برای موبایل

> نکته: تصویر بک‌گراند هیرو و عکس محصولات از یک سرویس تصویر رایگان و آنلاین بر اساس کلیدواژه گرفته می‌شوند (نیاز به اتصال اینترنت هنگام اجرا دارند). برای استفاده‌ی واقعی و حرفه‌ای:
> - عکس هیرو: در `src/index.css` مقدار `background-image` در کلاس `.hero` را به تصویر دلخواه خودتان تغییر دهید.
> - عکس محصولات: مقدار `img` هر آیتم را در `src/data/menuData.js` به مسیر عکس محلی خودتان تغییر دهید.
> - لوگو کاملاً محلی و SVG است (`src/components/Logo.jsx`) و نیازی به تغییر ندارد، مگر بخواهید طرح آن را شخصی‌سازی کنید.

## اجرا
```bash
npm install
npm run dev
```

سپس آدرس نمایش داده‌شده در ترمینال (معمولاً http://localhost:5173) را در مرورگر باز کنید.

## ساخت نسخه‌ی نهایی (Build)
```bash
npm run build
npm run preview
```

## ساختار پروژه
```
src/
  data/menuData.js      داده‌های نمونه‌ی منو
  components/
    Logo.jsx             لوگوی برند دلچین (SVG)
    ThemeToggle.jsx      دکمه‌ی تغییر تم
    SearchBar.jsx        نوار جست‌وجو
    MenuCard.jsx         کارت نمایش هر آیتم منو
  App.jsx                منطق اصلی صفحه + بخش هیرو
  index.css              استایل‌ها، بک‌گراند هیرو و متغیرهای تم
```

## شخصی‌سازی
- برای تغییر یا افزودن آیتم‌های منو، فایل `src/data/menuData.js` را ویرایش کنید.
- رنگ‌ها و ظاهر کلی از طریق متغیرهای CSS در ابتدای فایل `src/index.css` قابل تغییرند.
