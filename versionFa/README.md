# ذائقه — نمونه‌کار منوی رستوران، کافه و بستنی‌فروشی

یک پروژه‌ی نمونه (Portfolio) با React + Vite برای نمایش منوی رستوران، کافه و بستنی‌فروشی در یک صفحه.

## امکانات
- نمایش منو با قیمت برای سه بخش: رستوران، کافه، بستنی‌فروشی
- جست‌وجوی زنده بین نام، توضیحات و دسته‌بندی آیتم‌ها
- فیلتر بر اساس بخش (رستوران/کافه/بستنی‌فروشی) و دسته‌بندی داخلی هرکدام
- حالت تاریک (Dark) و روشن (Light) با ذخیره‌سازی انتخاب کاربر
- طراحی راست‌به‌چپ (RTL) و ریسپانسیو برای موبایل

## اجرا
```bash
npm install
npm run dev
```

سپس آدرس نمایش داده‌شده در ترمینال (معمولاً http://localhost:5173) را در مرورگر باز کنید.

## ساخت نسخه‌ی نهایی (Build)
```bash
npm run build
npm run preview
```

## ساختار پروژه
```
src/
  data/menuData.js      داده‌های نمونه‌ی منو
  components/
    ThemeToggle.jsx      دکمه‌ی تغییر تم
    SearchBar.jsx        نوار جست‌وجو
    MenuCard.jsx         کارت نمایش هر آیتم منو
  App.jsx                منطق اصلی صفحه
  index.css              استایل‌ها و متغیرهای تم
```

## شخصی‌سازی
- برای تغییر یا افزودن آیتم‌های منو، فایل `src/data/menuData.js` را ویرایش کنید.
- رنگ‌ها و ظاهر کلی از طریق متغیرهای CSS در ابتدای فایل `src/index.css` قابل تغییرند.
